# DeepLabV3-FracAtlas

This repository contains an implementation of DeepLabV3 for bone fracture segmentation across multiple backbone architectures, including **ResNet50**, **ResNet101**, and **MobileNetV3**. These models are trained and tested on FracAtlas, a complex and heterogeneous X-ray dataset. The dataset covers bone fractures across multiple anatomical regions including arms, legs, shoulders, and the hip.

This repository is an open-source implementation inspired by the Elsevier paper:

**“The impact of implementing backbone architectures on fracture segmentation in X-ray images”**
Turk et al., 2024

DOI: https://doi.org/10.1016/j.jestch.2024.101883
